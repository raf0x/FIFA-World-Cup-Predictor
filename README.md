# World Cup 2026 Predictor

A minimalist single-page predictor for the 2026 FIFA World Cup. Pick group winners, runners-up, and the 8 best third-place teams.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 3
- localStorage for persistence (no backend)

## Deploy

1. Create a new GitHub repo with these files
2. Import the repo into Vercel
3. Done. Vercel auto-detects Next.js and deploys

## Local dev (optional)

```
npm install
npm run dev
```
